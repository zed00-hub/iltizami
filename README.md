# التزام 🛡️ — تطبيق بناء العادات (Flutter / Android)

تطبيق عربي داكن يجعلك "دبابة التزام": عادات يومية وأسبوعية وشهرية وسنوية، سلاسل صارمة، أرقام قياسية لكل عادة، وتحليلات.

## الحصول على ملف APK (بدون تثبيت أي شيء على جهازك)

1. أنشئ مستودعًا جديدًا على GitHub (خاصًا أو عامًا).
2. ارفع محتويات هذا المجلد كلها (بما فيها المجلد المخفي `.github`).
3. افتح تبويب **Actions** ← سيبدأ البناء تلقائيًا (أو اختر **Build Iltizam APK** ثم **Run workflow**).
4. بعد 5–8 دقائق افتح التشغيل الناجح ← قسم **Artifacts** ← حمّل `iltizam-apk` ← فك الضغط ← انقل `app-release.apk` إلى هاتفك وثبّته (فعّل "التثبيت من مصادر غير معروفة").

## بناء محلي (اختياري)

```bash
flutter create --platforms=android --org com.iltizam --project-name iltizam .
rm -f test/widget_test.dart
python3 tool/patch_android.py
flutter pub get
flutter build apk --release --no-shrink
```

## المزايا (الإصدار 2)

**التبويبات:** اليوم · الخطط · التحليلات · الصلاة · المزيد

- **العادات:** تأكيد / عدّاد / مؤقّت، يومي وأسبوعي وشهري وسنوي. ثلاث حالات يدويًا: لم تُحدَّد · تمّت ✅ · فاتت ❌ (تتغير في أي وقت من اليوم).
- **الأيام القادمة:** تُعرض وتُخطَّط لها المهام فقط، بدون تأشير مسبق.
- **سلسلة صارمة** + أفضل سلسلة بتواريخها + قوة العادة % (ذاكرة أسية) + نقاط ومستويات وأوسمة.
- **"لماذا؟"** لكل عادة، وتحديات 30/66 يومًا.
- **الخطط والمهام:** سنوية ← شهرية ← أسبوعية ← يومية، ربط بخطة أب اختياري، وتختار لكل خطة هل يؤثر تقدّم الفرعية فيها. قائمة أو **مصفوفة أيزنهاور**، تصنيفات، مهام فرعية، مهام متكررة، تذكير.
- **الأدوية:** جرعات متعددة، مدة العلاج، مخزون، لكل دواء صفحته، وتأجيل (Snooze) من الإشعار نفسه.
- **بومودورو** مرتبط بالمهام، **صندوق أفكار سريع**، **مراجعة أسبوعية** تلقائية.
- **قياسات الجسم** بأسماء تختارها، **عادات الإقلاع** (عدّاد أيام نظيفة)، **يوميات المزاج**، **ختمة القرآن**، **متتبّع الصلوات الخمس**.
- **قفل PIN**، **وضع الإجازة/المرض** (يجمّد السلاسل)، **تصدير تقارير** (نص + CSV) ونسخ احتياطي.
- مواقيت الصلاة لـ58 ولاية (حساب محلي) + تقويم هجري. كل البيانات على هاتفك فقط.

## ملاحظات

- مواقيت الصلاة تقريبية (± دقيقة أو دقيقتين) بزاوية 18° للفجر و17° للعشاء والعصر مالكي؛ اعتمد على أذان المسجد عند الفرق.
- التقويم الهجري حسابي وقد يختلف يومًا عن الرؤية؛ يوجد ضبط ±.
- في بعض الهواتف (شاومي، أوبو…) فعّل "التشغيل التلقائي" وأوقف توفير البطارية للتطبيق ليصل التذكير في وقته.
- التأجيل من داخل الإشعار يعتمد على معالج خلفي لم يُجرَّب على جهاز حقيقي؛ إن لم يعمل فالتأجيل متاح من صفحة الدواء.
