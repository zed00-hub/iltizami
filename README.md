# التزام 🛡️ — تطبيق بناء العادات (Flutter / Android)

تطبيق عربي داكن يجعلك "دبابة التزام": عادات يومية وأسبوعية وشهرية وسنوية، سلاسل صارمة، أرقام قياسية لكل عادة، وتحليلات.

## الحصول على ملف APK (بدون تثبيت أي شيء على جهازك)

1. أنشئ مستودعًا جديدًا على GitHub (خاصًا أو عامًا).
2. ارفع محتويات هذا المجلد كلها (بما فيها المجلد المخفي `.github`).
3. افتح تبويب **Actions** ← سيبدأ البناء تلقائيًا (أو اختر **Build Iltizam APK** ثم **Run workflow**).
4. بعد 5–8 دقائق افتح التشغيل الناجح ← قسم **Artifacts** ← حمّل `iltizam-apk` ← فك الضغط ← انقل `app-release.apk` إلى هاتفك وثبّته (فعّل "التثبيت من مصادر غير معروفة").

## بناء محلي (اختياري)

```bash
flutter create --platforms=android --org com.iltizam --project-name iltizam .
rm -f test/widget_test.dart
python3 tool/patch_android.py
flutter pub get
flutter build apk --release
```

## المزايا

- عادات بثلاث طرق: **تأكيد** (نعم/لا)، **عدّاد** (أكواب ماء، صفحات…)، **مؤقّت** (دقائق دراسة/قراءة).
- فترات: يومي، أسبوعي (مثل 4 حصص رياضة)، شهري، سنوي. تقدر تسجل لأي يوم سابق.
- **سلسلة صارمة**: أي فترة فائتة تعيدها إلى الصفر. اليوم الجاري لا يكسرها قبل انتهائه.
- **أفضل سلسلة** مع تاريخ بدايتها ونهايتها، أفضل يوم/أسبوع، أقوى يوم في الأسبوع، نسبة الالتزام الكلية والأخيرة.
- **قوة العادة %**: متوسط متحرك أُسّي (ذاكرة أسية)، لا يصفّر تعب أشهر بسبب تعثّر عارض.
- نقاط ومستويات (من "مبتدئ" إلى "دبابة" إلى "لا يُقهَر") و14 وسامًا.
- رسوم: أعمدة، خريطة حرارية، تحليل أيام الأسبوع.
- مواقيت الصلاة لـ58 ولاية (حساب محلي بدون إنترنت) + تقويم هجري + تذكير مرتبط بالصلاة (مثل: قبل الفجر بـ20 دقيقة).
- إشعارات محلية: تذكير العادة، وحماية السلسلة الساعة 9:30 مساءً.
- كل البيانات على هاتفك فقط، مع نسخ احتياطي واستعادة عبر النسخ واللصق.

## ملاحظات

- مواقيت الصلاة تقريبية (± دقيقة أو دقيقتين) بزاوية 18° للفجر و17° للعشاء والعصر مالكي؛ اعتمد على أذان المسجد عند الفرق.
- التقويم الهجري حسابي وقد يختلف يومًا عن الرؤية؛ يوجد ضبط ±.
- في بعض الهواتف (شاومي، أوبو…) فعّل "التشغيل التلقائي" وأوقف توفير البطارية للتطبيق ليصل التذكير في وقته.
